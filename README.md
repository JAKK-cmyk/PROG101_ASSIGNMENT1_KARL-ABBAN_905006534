# Priority logic in brief

Risk level 3 is marked **URGENT – HUMAN REVIEW** and is not scored as ordinary waste. For other reports:

`PriorityScore = (2 × RiskLevel) + VolumeLevel + WaitingPoints`

Waiting points are 0 for 0–1 days, 1 for 2–3 days, and 2 for 4 or more days. A score of 8 or more is High; 5–7 is Medium; below 5 is Routine. These are sample classroom rules that must be reviewed locally before real use.

 Limitations and safeguards

This project is a logic design, not operational software. It cannot provide vehicles, staff, funding, or disposal facilities. Collect only information needed to follow up a report. Keep contact details optional and restricted to authorised users. Do not instruct residents to handle potentially hazardous material.
